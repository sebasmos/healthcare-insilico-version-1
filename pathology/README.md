# Pathology

Whole-slide cases: worklist, accessioning, slide storage and tiles, slide analysis, annotation import and export, sign-out. Page: `/pathology/`. The slide viewer is in `viewers/`.

- `server/`: code that runs on the server.
- `web/`: pages and scripts the browser loads. The path under `web/` is the address: `web/ehr/app.js` is served at `/ehr/app.js`.
