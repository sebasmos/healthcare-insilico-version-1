# Insurance and billing

The payer workbench and the hospital business office: plans, eligibility, prior authorisation, claims, appeals, coding, X12, Da Vinci profiles and the public reference data loader. Page: `/payer/`.

- `server/`: code that runs on the server.
- `web/`: pages and scripts the browser loads. The path under `web/` is the address: `web/ehr/app.js` is served at `/ehr/app.js`.
