# Desktop and sign-in page

The lock screen, the role picker, the desktop and its dock. The sign-in rules themselves are in `platform/server/` (`signin.mjs`, `accounts.mjs`, `roles.mjs`).

- `web/`: pages and scripts the browser loads. The path under `web/` is the address: `web/ehr/app.js` is served at `/ehr/app.js`.
