# EHR

The patient chart, Inbox, scheduling, orders, nursing (medication record, flowsheets, NEWS2), the bed board and remote monitoring with home readings and wearable streams. Pages: `/ehr/`, `/beds/`, `/monitoring/`.

- `server/`: code that runs on the server.
- `web/`: pages and scripts the browser loads. The path under `web/` is the address: `web/ehr/app.js` is served at `/ehr/app.js`.
