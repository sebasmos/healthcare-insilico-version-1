# PACS (radiology)

The radiology worklist, reporting with templates and dictation, DICOM storage and DICOMweb. Page: `/pacs/`. The image viewers themselves are in `viewers/`.

- `server/`: code that runs on the server.
- `web/`: pages and scripts the browser loads. The path under `web/` is the address: `web/ehr/app.js` is served at `/ehr/app.js`.
